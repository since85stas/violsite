# Таблица концертов

Скрипач ведёт афишу в Google Таблице. Сайт подтягивает изменения в течение ~15 минут.

## Колонки (первая строка таблицы — заголовки, ровно так)

| Колонка | Пример | Обязательно | Примечание |
|---|---|---|---|
| Дата | 22.11.2026 | да | ДД.ММ.ГГГГ |
| Время | 19:00 | нет | ЧЧ:ММ |
| Город | Москва | да | |
| Площадка | Зал «Зарядье» | да | |
| Программа | Бах. Партита № 2 | нет | |
| Тип | Сольный | нет | Сольный / С оркестром / Камерный / Другое |
| Билеты | https://… | нет | ссылка на продажу билетов |
| Показывать | да | да | «нет» — концерт скрыт с сайта |

Английская версия сайта показывает те же поля как есть. Если нужны переводы
программы, добавим колонки «Город (EN)», «Площадка (EN)», «Программа (EN)».

## Как опубликовать

1. Файл → Поделиться → **Опубликовать в интернете**.
2. Выбрать лист с концертами и формат **CSV**, нажать «Опубликовать».
3. Ссылку вставить в `config.php` на хостинге (`concerts_csv_url`)
   и в переменную `CONCERTS_CSV_URL` репозитория на GitHub.

## Как это работает

- **При сборке** сайт скачивает таблицу и вшивает афишу в HTML (видна поисковикам и без JavaScript).
  Ошибка сети сборку не ломает — афиша будет пустой, а браузер подтянет её через API.
- **В браузере** скрипт запрашивает `/api/concerts.php`. PHP скачивает таблицу не чаще раза в 15 минут
  (кэш `api/cache/concerts.json`), а если Google недоступен — отдаёт последний удачный кэш.
- Строки без даты, города или площадки, с несуществующей датой или «Показывать = нет» пропускаются.
  Ссылка на билеты принимается только `http(s)://`.
- Предстоящие концерты размечаются для поисковиков как `MusicEvent` (schema.org).

Логика разбора есть в двух местах — `src/lib/concerts-csv.ts` (сборка) и `public/api/concerts.php` (хостинг).
Меняя правила, правьте оба.

## Проверка

- Сборка на тестовой таблице: `CONCERTS_CSV_URL=docs/concerts-sample.csv npm run build`
  (в выводе — `[concerts] загружено концертов: 6`).
- PHP-разбор на той же таблице: `php tests/php/concerts.test.php`
  или без PHP: `npx -y @php-wasm/cli@3.1.59 tests/php/concerts.test.php`.
