# Таблица концертов

Елена ведёт афишу в Google Таблице. Изменения появляются на сайте через несколько минут
(столько Google обновляет опубликованную версию таблицы).

## Колонки (первая строка таблицы — заголовки, ровно так)

| Колонка | Пример | Обязательно | Примечание |
|---|---|---|---|
| Дата | 22.11.2026 | да | ДД.ММ.ГГГГ |
| Время | 19:00 | нет | ЧЧ:ММ |
| Город | Москва | да | |
| Площадка | Зал «Зарядье» | да | |
| Программа | Бах. Партита № 2 | нет | |
| Тип | Сольный | нет | Сольный / С оркестром / Камерный / Другое |
| Билеты | https://… | нет | ссылка на продажу билетов |
| Показывать | да | да | «нет» — концерт скрыт с сайта |

Английская версия сайта показывает те же поля как есть. Если нужны переводы
программы, добавим колонки «Город (EN)», «Площадка (EN)», «Программа (EN)».

Опубликованная таблица видна всем, у кого есть ссылка, — писать в неё только то, что и так будет на сайте.

## Как создать таблицу

Готовый шаблон — `docs/concerts-template.xlsx`. В нём уже настроено:
выпадающие списки «Тип» (Сольный / С оркестром / Камерный / Другое) и «Показывать» (да / нет),
формат даты ДД.ММ.ГГГГ с календарём и времени ЧЧ:ММ, проверка ввода, закреплённая строка заголовков,
подсказки в примечаниях к заголовкам, серый цвет для скрытых концертов и лист «Как заполнять».

1. В Google-аккаунте Елены: [sheets.new](https://sheets.new) → назвать «Концерты — сайт».
2. **Файл → Импорт → Загрузка** → `docs/concerts-template.xlsx` → **«Заменить таблицу»** → «Импортировать данные».
3. **Файл → Настройки → Региональные настройки: Россия** (чтобы даты были ДД.ММ.ГГГГ).
4. На листе «Концерты» есть строка-пример (серая, «Показывать = нет») — её можно исправить на настоящий концерт или удалить.
5. Заголовки в первой строке не переименовывать — по ним сайт находит колонки.
## Как опубликовать

1. Файл → Поделиться → **Опубликовать в интернете**.
2. Выбрать **лист «Концерты»** (не «Весь документ») и формат **CSV**, нажать «Опубликовать».
3. Ссылку вставить в переменную `CONCERTS_CSV_URL` репозитория на GitHub
   (Settings → Secrets and variables → Actions → Variables) и в `.env` для локальной сборки.

## Как это работает

- **При сборке** сайт скачивает таблицу и вшивает афишу в HTML (видна поисковикам и без JavaScript).
  Сборка запускается при каждом изменении кода, каждую ночь и вручную (Actions → Run workflow).
  Ошибка сети сборку не ломает — афиша будет пустой, а браузер подтянет её сам.
- **В браузере** скрипт скачивает ту же опубликованную таблицу и перерисовывает афишу —
  так новый концерт виден сразу, без пересборки. Если таблица недоступна (сеть, Google),
  остаётся версия со сборки.
- Строки без даты, города или площадки, с несуществующей датой или «Показывать = нет» пропускаются.
  Ссылка на билеты принимается только `http(s)://`. Текст из таблицы показывается как текст (HTML не выполняется).
- Предстоящие концерты размечаются для поисковиков как `MusicEvent` (schema.org).

Разбор CSV — один на сборку и браузер: `src/lib/concerts-csv.ts`.

**Проверить на настоящей таблице:** что браузер действительно может её скачать (Google должен
разрешать запросы с других сайтов — для опубликованных CSV обычно разрешает). Если нет — афиша
всё равно будет обновляться ночной пересборкой.

## Проверка

Сборка на тестовой таблице: `CONCERTS_CSV_URL=docs/concerts-sample.csv npm run build`
(в выводе — `[concerts] загружено концертов: 6`).
