# Что нужно от заказчика

Всё на двух языках (русский и английский), если не сказано иначе.
Английские тексты можно прислать на русском — переведём.

## Фото и видео
- [ ] Портрет для первого экрана (вертикальный, исходное качество)
- [ ] 10–20 фото для галереи: концерты, уроки, портреты — с подписями (где, когда)
- [ ] Картинка для превью ссылок (можно сделать из портрета)
- [ ] 3–6 ссылок на видео (YouTube) и их названия

## Тексты
- [ ] Короткая фраза для первого экрана и 1–2 предложения о себе
- [ ] Биография: короткая (2–3 абзаца) и полная — для пресс-кита
- [ ] Цифры: число концертов, годы преподавания, конкурсы, ученики

## Концерты
- [ ] Список ближайших и прошедших концертов (сразу в Google Таблицу — см. `concerts-sheet.md`)

## Уроки
- [ ] Для кого: возраст детей, взрослые, продолжающие — по 2–3 предложения
- [ ] Цены: пробный урок (платный), 45 и 60 минут, абонементы
- [ ] Адрес студии и метро
- [ ] Удобные дни и интервалы времени для пробных уроков
- [ ] 3–5 отзывов учеников с разрешением на публикацию

## Организаторам и контакты
- [ ] Почта для организаторов, телефон, Telegram, WhatsApp, соцсети
- [ ] Пресс-кит и репертуар в PDF (если нет — сделаем)

## Юридическое и доступы
- [ ] Статус: физлицо / самозанятый / ИП, ФИО — для политики конфиденциальности
- [ ] Почта для запросов по персональным данным
- [ ] Домен (выбрать и купить), хостинг с PHP
- [ ] Telegram, куда приходят заявки (создадим бота)
- [ ] Яндекс ID для Метрики, Вебмастера и Яндекс.Бизнеса
