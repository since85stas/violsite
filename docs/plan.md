## Принятые решения
- **Astro** → статический HTML, **без серверного кода**.
- **Хостинг — GitHub Pages** (бесплатно). Проверено 2026-11-15: из России открывается без VPN. Если появятся проблемы
  с доступностью — переезд на платный российский хостинг (папка `dist/` выкладывается как есть).
  Свой домен привязывается к Pages, когда будет куплен (README → «Свой домен»).
- **Сайт не собирает персональные данные.** Вместо формы заявки — выбор формата, дня и времени,
  из которых собирается текст; посетитель сам отправляет его Елене в MAX или Telegram
  (или звонит). Нет обработчика заявок, журнала, согласия на обработку ПД в форме.
- **Без счётчиков на сайте** (ни Яндекс.Метрики, ни своего). Аналитика — Вебмастер,
  Search Console, Яндекс.Бизнес. Свой счётчик был сделан для PHP-хостинга и удалён вместе с PHP
  (см. историю git, коммит «Добавить свой счётчик посещений…»), если понадобится — можно вернуть.
- **Языки:** русский (`/`) и английский (`/en/`).
- **Концерты** — Google Таблица (CSV): вшиваются при сборке (ночная пересборка) + браузер
  скачивает таблицу напрямую и обновляет афишу.
- **Пробный урок платный.** Желаемый день и интервал времени — без проверки занятости; Елена подтверждает в переписке.
- Дизайн — утверждённый прототип `docs/prototype/index.html` (минимализм + тёплый раздел уроков);
  имя на первом экране и в шапке — акцентным цветом.
