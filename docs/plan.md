## Принятые решения
- **Astro** → статический HTML; **российский хостинг с PHP** (Beget/Timeweb) — PHP только для кэша таблицы концертов.
- **Сайт не собирает персональные данные.** Вместо формы заявки — выбор формата, дня и времени,
  из которых собирается текст; посетитель сам отправляет его Елене в WhatsApp или Telegram
  (или звонит). Нет обработчика заявок, журнала, согласия на обработку ПД в форме.
- **Без Яндекс.Метрики.** Аналитика — свой счётчик `/api/hit.php` (только суммы по дням, без кук и IP,
  страница `/api/stats.php` под паролем) + Вебмастер, Search Console, Яндекс.Бизнес. См. `docs/stats.md`.
- **Языки:** русский (`/`) и английский (`/en/`).
- **Концерты** — Google Таблица (CSV): вшиваются при сборке + обновляются в браузере через PHP-кэш.
- **Пробный урок платный.** Желаемый день и интервал времени — без проверки занятости; Елена подтверждает в переписке.
- Дизайн — утверждённый прототип `docs/prototype/index.html` (минимализм + тёплый раздел уроков).
