## Принятые решения
- **Astro** → статический HTML; **российский хостинг с PHP** (Beget/Timeweb): данные из формы остаются в РФ.
- **Языки:** русский (`/`) и английский (`/en/`).
- **Концерты** — Google Таблица (CSV): вшиваются при сборке + обновляются в браузере через PHP-кэш.
- **Пробный урок платный.** В форме — желаемый день и интервал времени, без проверки занятости; подтверждение вручную.
- **Заявки** → Telegram-бот + почта + резервный журнал на хостинге.
- Дизайн — утверждённый прототип `docs/prototype/index.html` (минимализм + тёплый раздел уроков).
