# Статистика посещений

На сайте нет Яндекс.Метрики и других внешних счётчиков. Вместо них — свой простой счётчик,
который **не собирает персональные данные**: не сохраняет IP, User-Agent, куки и любые
идентификаторы посетителя, а только прибавляет единицу к суммам за день.

## Что считается

| Что | Как |
|---|---|
| Просмотры страниц | каждая загрузка страницы (RU / EN, главная / политика) |
| Источники | группа по домену, с которого пришли: Яндекс, Google, VK, Telegram, WhatsApp, YouTube, Instagram, 2ГИС, другие сайты, прямые заходы |
| Нажатия | элементы с атрибутом `data-goal` (список ниже) |

| `data-goal` | Где |
|---|---|
| `lesson_whatsapp`, `lesson_telegram` | кнопки «Написать» в записи на урок |
| `lesson_copy` | «Скопировать текст» |
| `lesson_call` | телефон в записи на урок |
| `tickets` | «Билеты» в афише |
| `video_play` | запуск видео |
| `presskit`, `repertoire` | PDF для организаторов |
| `org_contact` | контакты в разделе «Организаторам» |

Новую цель: добавить `data-goal="имя"` на элемент и имя с подписью в `STATS_EVENTS` в `public/api/stats-lib.php`
(неизвестные имена сервер отбрасывает).

**Чего нет и не будет без кук:** уникальных посетителей, вебвизора, демографии, путей по сайту.
Перезагрузка страницы — ещё один просмотр. Боты отсеиваются по User-Agent (сам User-Agent не сохраняется).

## Как устроено

```
браузер (Base.astro) ──sendBeacon──▶ /api/hit.php ──+1──▶ api/cache/stats/ГГГГ-ММ.json
                                                            │
Елена ──логин/пароль──▶ /api/stats.php ◀───────────────────┘
```

- `hit.php` принимает запросы только со своего домена; локально (localhost) скрипт ничего не отправляет.
- Файл за месяц выглядит так: `{"2026-11-11":{"views":{"/":42},"events":{"lesson_whatsapp":3},"sources":{"yandex":20}}}`.
- Деплой эти файлы не трогает (`--filter='P api/cache/**'`).

## Страница статистики

`https://домен/api/stats.php` — закрыта логином и паролем (`stats_user`, `stats_password` в `api/config.php`).
Пустой пароль — страница отключена (404). Поисковикам закрыта (`noindex`).

Показывает за 7 / 30 / 90 дней или год: просмотры, сколько раз нажали «Написать» / «Позвонить»,
источники, нажатия по кнопкам, страницы и таблицу по дням.

## Что ещё подключить (бесплатно, без кода на сайте)

- **Яндекс.Вебмастер** и **Google Search Console** — поисковые запросы, показы, переходы из поиска.
- **Яндекс.Бизнес** и **Google Business Profile** — просмотры карточки «Уроки скрипки», звонки, маршруты.
