Исходные изображения (Astro сам сожмёт и сделает WebP/AVIF):

- `portrait/` — портрет для первого экрана (вертикальный, от 1600px по длинной стороне)
- `gallery/` — фото галереи; имена файлов прописываются в `src/data/gallery.json`

Картинка для превью ссылок в мессенджерах — `public/og-image.jpg` (1200×630).
- `venues/` — логотипы залов и фестивалей для ленты в «О себе»: `<id>.svg` из `src/data/venues.json`,
  одноцветные (цвет задаёт сайт). Нет файла — вместо логотипа набирается название.
