Отдельных скриптов здесь нет — клиентский JS лежит в `<script>` внутри компонентов
(Astro сам собирает и подключает его):

| Компонент | Что делает скрипт |
|---|---|
| `Header.astro` | Бургер-меню: открытие, закрытие по ссылке, Esc и клику мимо |
| `Concerts.astro` | Вкладки афиши, перенос прошедших концертов, обновление из опубликованной Google Таблицы |
| `Media.astro` | Подмена обложки видео на плеер по клику |
| `Gallery.astro` | Фильтры, полноэкранный просмотр (стрелки, Esc, свайп) |
| `BookingForm.astro` | Дни для записи, текст сообщения, ссылка Telegram с текстом, MAX — копирование текста и открытие чата |
