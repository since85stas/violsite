Клиентские скрипты (подключаются в компонентах через `<script>`):

| Файл | Этап | Что делает |
|---|---|---|
| `concerts.ts` | 4 | Вкладки афиши, обновление списка из `/api/concerts.php` |
| `gallery.ts` | 3 | Фильтры галереи, лайтбокс (стрелки, Esc, свайп) |
| `video.ts` | 3 | Подмена превью YouTube на плеер по клику |
| `booking.ts` | 5 | Дни для записи, проверка формы, отправка в `/api/lead.php` |

Логику можно взять из прототипа: `docs/prototype/index.html`.
